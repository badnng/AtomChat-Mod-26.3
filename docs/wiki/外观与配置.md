**设置页里有什么、怎么换头像和壁纸、以及配置文件里那几十个键分别是什么。**

## 设置页

底部第三个标签 **设置** 包含 **外观 / 聊天 / 隐私与屏蔽 / 关于**。默认 AtomChat 界面保留 Win11 风格的 2×2 磁贴主页；MIUIX 界面会在同一个 Minecraft 面板内用 Miuix 偏好设置页呈现这些分区。

设置改动无需重启游戏，并会在提交后自动保存。AtomChat 界面的颜色项带预设色板、`+` 自定义拾色器和实时预览色块。MIUIX 保留 Miuix 默认排版、语义色和组件样式，只将 AtomChat 强调色覆写到主题主色；已配置的聊天气泡填充色与文字色仍用于消息内容。

## 外观

| 选项 | 说明 |
|---|---|
| 主题预设 | `毛玻璃`（frosted）/ `现代`（modern）一键切换。预设会改外观值，但不会切换界面风格或 MIUIX 底部导航选项。 |
| 界面风格 | AtomChat 界面可在 **设置 → 外观 → 主题标签 → 界面风格** 切换；MIUIX 界面可在 **设置 → 外观 → 界面风格** 切换。选择 `AtomChat`（默认）或 `miuix`，本地即时生效并保存，也可随时切回。MIUIX 版目前提供于 26.3 NeoForge，并使用官方 Miuix Compose 组件；会继续使用已配置的强调色与聊天气泡颜色。 |
| Miuix 主题 | 在 MIUIX **设置 → 外观** 中选择 `浅色` 或 `深色`。这会选择 Miuix 语义配色，并更新用于选择主题明暗的面板颜色。 |
| miuix 底部导航 | 在 AtomChat **外观 → 主题** 或 MIUIX **设置 → 外观** 中选择 `仅图标`、`图标与文字`（MIUIX 默认）、`选中项文字`、`悬浮式`。此选项独立保存，仅在 MIUIX 界面下生效，对应 Miuix `NavigationBar` 与 `FloatingNavigationBar`；悬浮式使用带模糊的胶囊背景。 |
| 背景模糊 | 模糊面板后的游戏世界；**与自定义壁纸互斥**。MIUIX 的 OpenGL 路径最高以 60 Hz 采样世界，用异步 96×54 探针检测变化，并至少每 125 ms 更新一次；Vulkan 路径仅异步读取面板区域，复用一个暂存缓冲区，最多同时有一个请求，最高 30 Hz。运行时着色器可用时，Miuix 对页面使用纹理模糊，并对顶栏和输入栏使用渐进式纹理模糊。 |
| 面板不透明度 | 0–100%，模糊开或关都作用于底色；MIUIX 也用它调节页面玻璃色调和壁纸透明度。顶栏使用独立的、随折叠进度变化的色调。 |
| 面板宽度 | 400–600（设计像素） |
| 界面缩放 | x0.75 – x1.50，整套 UI（含布局与命中测试）一起缩放 |
| 消息入场动画 | QQ 式横向滑入 + 淡入 |
| 动画总开关 | 关掉装饰动效（进出场、页面推入、戳一戳、滚动吸附）；悬停高亮这类**功能性反馈不受影响**。 |
| 双击头像戳一戳 | 开关 |
| 全部界面配色 | AtomChat 可调整面板背景 / 自己的气泡 / 他人的气泡 / 气泡文字 / 次要胶囊 / 主次文字 / 卡片 / 描边 / 强调色，每项带实时预览。MIUIX 使用已配置的强调色与聊天气泡配色；组件继续使用 Miuix 默认语义色。 |
| 面板圆角 | 游戏内滑块调整面板外围圆角。MIUIX 将此值用于面板外框，内部组件保留 Miuix 默认圆角。 |

MIUIX 根标签共用一个 Scaffold，并保留原生底部导航选中指示器；仅页面内容使用 160 ms 交叉淡入淡出。`pageNavStyle`（`SLIDE` / `ZOOM`）只控制二级页面推入 / 返回。`SLIDE` 使用 500 ms 滑动，覆盖页带四分之一宽度视差。`ZOOM` 先用 180 ms 缩小并淡出当前页，再延迟 180 ms 开始新页的 260 ms 放大淡入（从 110% 缩放到正常大小）。动画总开关会停用这些转场。

大标题随页面滚动折叠，聊天页也使用同一行为。顶栏渐进式玻璃随折叠进度从表面色调过渡到压暗层，并在栏下保留柔和边缘；面板不透明度不缩放顶栏色调。

重建 renderer session 时，临时弹层会关闭，未提交的 IME 预编辑会取消；可保存的滚动位置从内存恢复，导航与聊天草稿仍由 Java host 保存。同一 GPU session 内仅更换尺寸目标时会保留 Compose 场景，因此临时弹层仍然打开。

MIUIX 以用户批准的 Miuix 原生风格截图为视觉基准，使用 Miuix 默认排版、语义色和组件样式，仅用 AtomChat 强调色覆写主题主色；已配置的气泡颜色仍用于消息。卡片色调、卡片颜色、面板描边、主次文字和胶囊配色等旧版选项留在 AtomChat 界面；切换风格不会清除其保存值。MIUIX 的设置 → 外观页提供主题模式、底部导航和面板圆角选项。

### 自定义头像

`外观 → 自定义头像` → 选图 → 进入裁剪器：

- **拖动**平移图片，**滚轮**围绕取景框缩放，**双击**重置；
- 输出为 256 像素的方形 PNG，存在 `.minecraft/config/atomchat/avatar/`；
- 同一服务器上装了 AtomChat 的玩家会**自动拿到你的头像**（换头像即时广播刷新）；对方没装 / 服务器关了托管时，静默降级为皮肤头像。

### 自定义壁纸

`外观 → 自定义壁纸` → 选图 → 同样的裁剪器交互。图片会降采样（长边 ≤ 1024 像素）后存进 `.minecraft/config/atomchat/wallpaper/`，支持 `png` / `jpg` / `jpeg` / `webp`。

壁纸与背景模糊**互斥**；两者都在时以壁纸为准，用`面板不透明度`压暗壁纸以保证文字可读。

## 聊天

MIUIX 聊天按已批准截图排版：消息文字为 17 sp，气泡最大宽度为 320 dp。自己的消息靠右显示，不带头像和发送者名称；未分组的其他玩家消息显示头像与名称。时间戳（存在时）和 More 操作放在气泡底部同一行。输入栏第一行左侧为文字框、右侧为发送按钮；下一行依次为表情、贴纸、短语和图片操作。

对启用了戳一戳的其他玩家头像，单击会等待最多 300 ms，让第二次点击可以触发原有戳一戳动作，而不是打开个人资料；右键消息或点击 More 会打开现有消息操作菜单。

世界聊天筛选保留原有的“全部 → 系统 → 玩家”循环。原版筛选、公告和玩家图标及其色调随选项切换，图标使用短暂淡入淡出。

MIUIX 个人资料在 Miuix 卡片中保留原版横幅、重叠头像、签名、延迟 / 本次会话 / 挖掘统计，以及身份 / 服务器 / UUID 信息。编辑本人资料和操作其他玩家仍沿用现有可用条件及后端动作。

| 选项 | 默认 | 说明 |
|---|---|---|
| 图片消息 | 开 | 关掉后不下载不缓存，显示绿色 `[图片]` 占位 |
| 时间戳分隔 | 每 5 分钟 | 首条消息始终显示；`0` = 关闭 |
| 防刷屏合并 | 开 | 连续相同消息合并为一条并显示次数 |
| 紧凑消息分组 | 关 | 同一发送者 5 分钟内的连续消息只保留第一条的头像与名字 |
| 保留聊天记录 | 关 | 开启后按服务器 / 世界存到 `.minecraft/config/atomchat/history/`（JSONL），重进同一服务器恢复 |
| 历史保留天数 | 7 | `0` = 永久 |
| 通知（@ / 引用 / 私聊） | 开 | 横幅与音效可分别开关，另有总音量 |
| 传送模式 | `auto` | 在 `/tp` / `/tpa` / `auto` 之间循环；`auto` 会探测服务器命令树 |

## 隐私与屏蔽

- **屏蔽名单**：可视化列表（头像 + 名字 + 一键取消）；
- **隐藏被屏蔽玩家的消息**：默认开。关掉后公屏仍可看到其消息，但私聊保持屏蔽；
- **接收本服下发内容**：默认开。关掉后不再向服务器请求表情 / 常用语 / 服务端标识，并立即清空已加载的视图。

版本、许可证、仓库链接、当前页面列出的第三方组件（Skija / Skia / FlatLaf），以及两个操作。完整打包依赖见 [`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md)。

- **清除图片缓存** —— 只清 `<游戏目录>/atomchat-data/` 里的图片缓存，**不影响**表情包 / 壁纸 / 头像；
- **调试模式** —— 打开后会把头像取色采样写成 PNG 到 `.minecraft/config/atomchat/debug/`，排查头像颜色问题用。

## 配置文件与数据落点

游戏内能改的都能改，但想批量编辑或提前配置，直接改文件即可。主配置：**`.minecraft/config/atomchat/atomchat-client.json`**（首次启动自动生成）。

> 手改文件后需要**重启游戏**。唯一例外是 `chatTemplates` / `whisperTemplates`：它们在每次打开聊天界面时重读。

| 路径 | 内容 |
|---|---|
| `config/atomchat/atomchat-client.json` | 客户端主配置 |
| `config/atomchat/avatar/` | 自定义头像（256px PNG） |
| `config/atomchat/emotes/` | 你自己的表情包（默认不限量，`emoteMax` 可设上限） |
| `config/atomchat/server-emotes/` | **仅服务端**：下发给客户端的分发源 |
| `config/atomchat/wallpaper/` | 自定义壁纸 |
| `config/atomchat/history/` | 聊天记录（默认关，按服务器 / 世界分文件） |
| `config/atomchat/debug/` | 调试模式下导出的头像采样 PNG |
| `<游戏目录>/atomchat-data/` | 图片缓存、服务端下发的包、他人头像数据（500 文件 / 100 MB / 7 天未用自动清理） |

服务端自己的配置与数据在服务端游戏目录下，见 [服主手册](服主手册)。
